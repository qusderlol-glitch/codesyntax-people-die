Это безопасно?Is it safe?

Установщик скачивает файлы только с этого GitHub-релиза и сверяет каждый с SHA-256 из встроенного манифеста; изменённый файл будет отклонён. Игра не собирает данные.

The installer downloads files only from this GitHub release and checks each against the SHA-256 in its embedded manifest; a modified file is rejected. The game collects no data.
