FAQ

Нужен ли Godot?Do I need Godot?

Нет. Игра — обычное приложение для Windows, ничего дополнительно ставить не надо.

No. The game is a regular Windows application; nothing else to install.

Это безопасно?Is it safe?

Установщик скачивает файлы только из релизов этого проекта на GitHub и сверяет каждый с SHA-256 из встроенного манифеста; изменённый файл отклоняется. Игра не собирает данные.

The installer downloads files only from this project’s GitHub releases and checks each one against the SHA-256 in its embedded manifest; a modified file is rejected. The game collects no data.

Почему на VirusTotal «9 из 69»? Это вирус?Why does VirusTotal show “9 / 69”? Is it a virus?

Короткий ответ: это ложные срабатывания. Отчёт VirusTotal для установщика v0.7.6 показывает, что 9 из 69 антивирусов что-то нашли. Но посмотрите, какие именно: Arctic Wolf, Bkav Pro, CrowdStrike Falcon, Elastic, Malwarebytes, MaxSecure, SecureAge, Symantec и Trapmine. Все их вердикты — «ML», «MachineLearning», «Anomalous», «confidence», «susgen» — то есть это эвристика и нейросети, которые угадывают «похоже на вредонос», а не опознают конкретный вирус. Названия настоящего семейства вредоносов (троян, стилер и т.п.) нет ни у одного. Остальные движки, включая Microsoft Defender, Kaspersky, ESET, BitDefender, Avast, Sophos, McAfee и Google, ничего не нашли.

Почему так происходит. Установщик новый, маленький (около 0,6 МБ), без цифровой подписи и без «репутации» — его ещё не скачали миллионы людей. И он делает то, что делают и настоящие вредоносные «загрузчики»: скачивает файлы из интернета (по частям с GitHub), записывает их на диск, создаёт ярлыки, прописывает запись об удалении в реестре текущего пользователя, копирует сам себя как uninstall.exe и запускает игру. Эвристика видит это сочетание и перестраховывается. Это известная проблема для любых небольших неподписанных установщиков, в том числе у независимых разработчиков игр.

Что установщик делает и чего не делает. Он скачивает файлы только из релизов этого проекта на GitHub, проверяет каждый по SHA-256 и ставит всё в вашу папку пользователя (без прав администратора). Он не собирает данные и не устанавливает ничего постороннего.

Как проверить самому. Сравните SHA-256 скачанного файла с тем, что указан наверху страницы (PowerShell: Get-FileHash CodeSyntax_Setup.exe) — если совпадает, файл тот же, что мы выложили, и никто его не подменил. Если вам всё равно неспокойно, запустите установку в виртуальной машине или не ставьте игру: это ваше право. Со временем (когда файл скачают много людей) и после появления цифровой подписи таких срабатываний обычно становится меньше; ложное срабатывание также можно отправить в сам антивирус, который его показал.

Short answer: these are false positives. The VirusTotal report for the v0.7.6 installer shows 9 of 69 engines flagging it. Look at which ones: Arctic Wolf, Bkav Pro, CrowdStrike Falcon, Elastic, Malwarebytes, MaxSecure, SecureAge, Symantec and Trapmine. Every one of their verdicts is “ML”, “MachineLearning”, “Anomalous”, “confidence” or “susgen” — that is, heuristics and machine-learning guesses of “this looks suspicious”, not the identification of a specific virus. None of them names an actual malware family (trojan, stealer, etc.). The other engines, including Microsoft Defender, Kaspersky, ESET, BitDefender, Avast, Sophos, McAfee and Google, found nothing.

Why it happens. The installer is new, tiny (about 0.6 MB), not code-signed and has no “reputation” yet — millions of people haven’t downloaded it. And it does what real malicious “downloaders” also do: it fetches files from the internet (in parts, from GitHub), writes them to disk, creates shortcuts, adds an uninstall entry to the current user’s registry, copies itself as uninstall.exe and launches the game. Heuristics see that combination and play it safe. This is a well-known problem for any small unsigned installer, including those of independent game developers.

What the installer does and does not do. It downloads files only from this project’s GitHub releases, verifies each one against its SHA-256 and installs everything into your user folder (no administrator rights). It does not collect data and does not install anything unrelated.

How to check it yourself. Compare the SHA-256 of the file you downloaded with the one at the top of this page (PowerShell: Get-FileHash CodeSyntax_Setup.exe) — if it matches, it is exactly the file we published and nobody swapped it. If you are still uneasy, run the installer in a virtual machine or skip the game; that is your call. Such detections usually fade as more people download the file and once the installer is code-signed; you can also report a false positive to the antivirus that raised it.

Почему SmartScreen ругается?Why does SmartScreen warn me?

У установщика пока нет цифровой подписи, а Windows с подозрением относится к малоизвестным неподписанным файлам. Нажмите «Подробнее» → «Выполнить в любом случае».

The installer has no code-signing certificate yet, and Windows is wary of little-known unsigned files. Click “More info” → “Run anyway”.

Use the Report Bug button in the in-game menu, or open an issue in the GitHub repository.
